# 🏥 ระบบติดตามงานซ่อมบำรุงโรงพยาบาล (Hospital Maintenance System)

ระบบบริหารจัดการและติดตามงานแจ้งซ่อมบำรุงที่ออกแบบขึ้นเฉพาะสำหรับ **โรงพยาบาลและหน่วยงานสาธารณสุข** รองรับทั้งงานเครื่องมือแพทย์, ระบบกายภาพ/อาคาร, งานเทคโนโลยีสารสนเทศ (IT) และครุภัณฑ์ทั่วไป ตามมาตรฐานการพัฒนาคุณภาพโรงพยาบาล (HA)

---

## 🌟 จุดเด่นที่ปรับให้เหมาะกับ "โรงพยาบาล"

1. **คัดกรองระดับความเร่งด่วน (Urgency Triage):**
   - 🔴 **ฉุกเฉินวิกฤต (ทันที):** กระทบชีวิตผู้ป่วยหรือจุดวิกฤต เช่น ER, ICU, ห้องผ่าตัด (OR)
   - 🟠 **ด่วนมาก (ภายใน 2 ชม.):** กระทบต่อระบบบริการผู้ป่วยหลัก เช่น เครื่องพิมพ์ฉลากยา, เครื่องวัดสัญญาณชีพ
   - 🟡 **ด่วน (ภายใน 24 ชม.):** รบกวนการทำงานของเจ้าหน้าที่
   - 🟢 **ปกติ (ภายใน 48 ชม.):** ซ่อมบำรุงทั่วไป / เชิงป้องกัน
2. **แยกหมวดหมู่งานซ่อมตามโครงสร้าง รพ.:**
   - 🩺 **เครื่องมือแพทย์ (Medical Equipment):** เครื่องวัดความดัน, Defibrillator, เครื่องช่วยหายใจ, Syringe Driver
   - 🏢 **ระบบอาคารและกายภาพ (Facilities):** ไฟฟ้า, แอร์, ประปา, ก๊าซทางการแพทย์ (Medical Gas)
   - 💻 **ระบบสารสนเทศ (IT & HIS):** คอมพิวเตอร์, HosXP/HIS, เครื่องสแกนบาร์โค้ด, เครื่องพิมพ์ฉลากยา
   - 🪑 **ครุภัณฑ์ทั่วไปและยานพาหนะ:** เตียงคนไข้, รถเข็นนั่ง/นอน, รถพยาบาล (Ambulance)
3. **ระบบรหัสใบงานอัจฉริยะ (Smart Ticket ID):**
   - แยกตามสายงาน เช่น `REQ-MED-20261118-101`, `REQ-FAC-20261118-202`, `REQ-IT-20261118-303`
4. **ถ่ายรูปแนบอาการเสียจากมือถือได้ทันที (Camera / Mobile Attachment):**
   - ถ่ายรูป Error Code หรือจุดชำรุด พร้อมระบบ Auto-Resize ช่วยให้โหลดเร็ว ไม่เปลืองพื้นที่
5. **ระบบป้องกันกดซ้ำ (Anti-Double Submit):**
   - ปุ่มจะล็อกและแสดงสถานะ Loading ป้องกันเจ้าหน้าที่กดย้ำขณะเน็ตช้า

## 🏗️ โครงสร้างการทำงาน 3 ส่วนหลัก

```
[🖥️ Frontend (Web App / Mobile)]
   ├─ หน้าฟอร์มแจ้งซ่อม (Floating Labels + Photo Upload + Anti-Duplicate Submit)
   ├─ หน้าติดตามสถานะงาน (ค้นหาด้วยเลขใบงาน / เบอร์โทร + Timeline สเต็ป 1-2-3)
   └─ หน้ากระดานช่าง (Dashboard สรุปสถิติงาน + อัปเดตสถานะ + ส่งออก Excel)
          │
          ▼ (ส่งข้อมูลแบบ Real-time)
[⚙️ Backend & Logic]
   ├─ ทางเลือก A: Google Apps Script (Cloud Serverless / ฟรี 100% / นิยมใน รพ.)
   ├─ ทางเลือก B: REST API / PHP / Node.js (สำหรับติดตั้งบน Intranet รพ.)
   └─ แจ้งเตือนเข้ากลุ่ม LINE Notify ของทีมช่าง รพ. ทันที
          │
          ▼ (Auto-Append บันทึกต่อท้ายอัตโนมัติ)
[📊 Database]
   ├─ Google Sheets: เป็นฐานข้อมูลเปิดดูง่ายผ่านมือถือหรือคอมพิวเตอร์
   └─ SQL Database: MySQL / MariaDB (กรณีเชื่อมโยงเข้าฐานข้อมูลส่วนกลางของ รพ.)
```

## 🚀 วิธีการติดตั้งและเริ่มใช้งาน

### 1. ทดลองใช้งานทันที (Offline / Local Mode)
- ดับเบิลคลิกเปิดไฟล์ `index.html` ใน Google Chrome, Microsoft Edge หรือ Brave
- ระบบสามารถ **บันทึก แจ้งซ่อม ค้นหาสถานะ และอัปเดตงาน** ผ่านระบบฐานข้อมูลจำลอง (LocalStorage) ได้ทันที 100% โดยไม่ต้องติดตั้งเซิร์ฟเวอร์

---

### 2. เชื่อมต่อ Google Sheets + LINE Notify (แนะนำสำหรับ รพ.)
หากต้องการให้ข้อมูลไปลง Google Sheets ของโรงพยาบาล และเด้งเตือนเข้ากลุ่มไลน์ช่าง:

1. เข้า [Google Sheets](https://sheets.new) สร้างสเปรดชีตใหม่ ตั้งชื่อว่า **"ระบบแจ้งซ่อมโรงพยาบาล"**
2. ไปที่เมนู **ส่วนขยาย (Extensions)** → **Apps Script**
3. คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ไปวางแทนที่โค้ดเดิม
4. (ตัวเลือกเสริม) ใส่ `LINE_NOTIFY_TOKEN` ในบรรทัดที่ 11 หากต้องการให้แจ้งเตือนเข้าไลน์กลุ่ม
5. กดปุ่ม **การทำให้ใช้งานได้ (Deploy)** → **การทำให้ใช้งานได้รายการใหม่ (New Deployment)**
   - เลือกประเภท: **เว็บแอป (Web App)**
   - กำหนดสิทธิ์ **ผู้ที่มีสิทธิ์เข้าถึง (Who has access)**: **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้หน้าเว็บส่งข้อมูลเข้าได้)*
   - กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)**
6. เปิดหน้าเว็บ `index.html` → กดไอคอนรูป ⚙️ (มุมขวาบน) → วาง Web App URL ลงในช่องแล้วกด **บันทึกการตั้งค่า**
7. **เสร็จสิ้น!** เมื่อมีคนแจ้งซ่อม ข้อมูลจะบันทึกลง Google Sheets และส่งเข้ากลุ่ม LINE ทันที

## 🔁 Workflow การทำงานจริงในโรงพยาบาล

```
[ เจ้าหน้าที่ / พยาบาล ]
        │
        ▼ 1. สแกน QR Code หรือเปิดลิงก์เว็บผ่านมือถือ/คอมฯ
        ▼ 2. เลือกแผนก (เช่น ER, OPD, IPD) และหมวดหมู่งาน
        ▼ 3. ถ่ายรูปอาการเสีย / ระบุความเร่งด่วน → กด "ส่งแจ้งซ่อม"
        │
[ ระบบอัตโนมัติ ]
        │
        ▼ 4. สร้าง Ticket ID (เช่น REQ-MED-20261118-001)
        ▼ 5. บันทึกลงตารางทันที + ส่ง LINE Notify แจ้งช่างเวร
        ▼ 6. แสดงหน้าต่างยืนยันบนจอมือถือ พร้อมปุ่มคัดลอกเลขใบงาน
        │
[ ช่างซ่อมบำรุง / ทีม IT ]
        │
        ▼ 7. ได้รับแจ้งเตือนทาง LINE หรือดูกระดาน Dashboard
        ▼ 8. รับเรื่อง → เปลี่ยนสถานะเป็น "กำลังดำเนินการ"
        ▼ 9. เข้าแก้ไขหน้างาน → บันทึกผลการซ่อม → เปลี่ยนสถานะเป็น "ซ่อมเสร็จสิ้น"
        │
[ ผู้แจ้ง / หัวหน้าแผนก ]
        │
        ▼ 10. ตรวจสอบสถานะงานแบบ Real-time ผ่านแถบ "ติดตามสถานะ"
```

## 📈 ประโยชน์ที่โรงพยาบาลได้รับ
- ✔️ **ตอบสนองเคสวิกฤตได้ทันท่วงที:** มีระบบ Triage แยกงานฉุกเฉินใน ER/ICU ชัดเจน
- ✔️ **ลดความผิดพลาดด้านการสื่อสาร:** ระบุตึก ชั้น ห้อง เบอร์เตียง และเลขครุภัณฑ์ได้ชัดเจน
- ✔️ **รองรับมาตรฐาน HA:** มี Log บันทึกวันเวลาที่แจ้ง, ช่างผู้รับผิดชอบ, และเวลาที่ซ่อมเสร็จ สามารถ Export เป็น Excel/CSV เพื่อทำรายงานสรุปประจำเดือน/ประจำปีได้
- ✔️ **ไร้กระดาษ 100%:** เจ้าหน้าที่แจ้งผ่านสมาร์ตโฟนได้ทุกจุดในโรงพยาบาล
